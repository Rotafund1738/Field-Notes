# Field Notes

This repository serves as an ongoing consolidation of my experience - successes and blunders - during Hack The Box labs.

The objective is to document the investigation process, technical findings, troubleshooting methodology, and lessons learned while ultimately detailing the thought process involved.

The purpose of this documentation is for future review and potential discussion, serving as an exact record of how considerations were made at any point in time. The unfiltered nature preserves the authenticity (and makes it more fun to write), retaining 100% of the process.
